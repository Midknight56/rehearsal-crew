# Who does the work

- Kiro does every task in this repository: the spec, the steering, the tests, the code, the docs and the log.
- No file in the repository mentions any other tool as an author or helper.
- The one piece of outside work is the engine copy in `engine/`. It is Rehearsal's own source, copied unchanged. `engine/SOURCE.md` names the commit it came from and lists a sha256 for each copied file.
- No file names a prize, a budget or another project. The Rehearsal repository is named only where the app needs it: the engine source, the licence notice and the README link.
- No file holds a Windows user folder path, a token, a key or an email address. Where a path is needed, write `<REHEARSAL_REPO>`.
- Every finished task gets a tick in `.kiro/specs/rehearsal-crew/tasks.md` and one row in `docs/kiro-log.md`, the same day.
- A check that fails twice after repairs stops the work. Report the item and the failing output. Never weaken a test to make it pass.
